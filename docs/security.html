更改邮箱

为防止账号被盗，更改邮箱需要邮箱验证：提交后系统会向新邮箱发送确认邮件， 点开确认后才会生效。在确认完成之前，当前邮箱仍然可用。

注销账号

注销是不可逆的操作。为了防止误操作，需要先完成邮箱验证，然后手动输入一句确认短语。 提交后你会从所有设备退出登录，账号将在 3 天后进入已注销状态。

申请注销，先验证邮箱

邮箱已验证。请把下面这句话原样输入到输入框里（含标点），以确认你了解并同意：

我确认注销账号，并允许服务器将我的账号数据继续存放60天
