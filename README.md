# HomeworkShower · 作业看板

同学打开网页就能看到今天的作业。作业由桌面端 **StickyHomeworks2** 导出后发布上来，同一天重复发布会覆盖当天内容。

在线地址：**https://dogoffurina114514.github.io/HomeworkShower/**

---

## 一、怎么用

### 同学（只想看作业）

1. 打开上面的网址，**不用登录**就能看到还没过期的作业；
2. 想看以前的作业，点右上角 **时光机** → 登录后点日期框，在日历里选一天；
3. 顶部出现红色横幅说明你还没登录 —— 登录后才能用时光机。

### 发布者（发布作业 / 修改作业）

1. 在桌面端 StickyHomeworks2 里整理好当天的作业，用 **保存作业 → JSON** 导出文件；
2. 网页右上角 **个人中心 → 发布作业**（或右下角编辑按钮 → 发布作业）；
3. 选择导出的 JSON 文件（或直接把 JSON 粘进去），点 **发布到这一天** —— 归属日期固定是今天，只能发当天。

### 修改 / 删除某条作业

在看板上**点一下那条作业**，它会变成选中状态，下方出现 **修改** 与 **删除** 两个按钮：

- **修改**：可以改科目、期限、标签，以及正文（正文是富文本，支持加粗 / 斜体 / 下划线 / 列表 / 链接 / **插图**）；
- **删除**：会二次确认，删掉就没了。

> 只有**发布者**和**管理员**能改，而且**只能改当天**发布的内容。

### 想成为管理员

在右下角点 **编辑按钮** → 弹出「仅管理员可修改作业」→ 点 **申请管理员** → 弹窗里是管理员的邮箱，
点 **打开「电子邮件」** 就会唤起你的邮件应用，收件人和主题（申请作业管理员）都填好了，补上理由发送即可。

## 二、功能一览

| 页面 | 能做什么 |
| --- | --- |
| **作业看板**（主页） | 看当天 / 最近一次发布的作业；只显示还没过期的；点作业可修改或删除（有权限时） |
| **时光机** | 按**发布日期**回看某一天的作业（含已过期的）；需要登录；只能看，不能改 |
| **登录 / 注册** | 邮箱 + 密码注册，注册后要去邮箱点验证链接；未验证就登录会弹窗提示并可重发验证邮件 |
| **验证成功页** | 点完邮件里的链接跳到这里，点一下就能进看板 |
| **发布作业** | 导入桌面端导出的 JSON，发布到当天（仅发布者） |
| **个人中心** | 右上角，显示当前邮箱与身份，发布者多一个「发布作业」入口，以及退出登录 |

**界面细节**

- 未登录时：顶部一条红色横幅建议登录，右上角按钮直接从「个人中心」变成「登录」；
- 作业卡片：左侧圆点、科目分组、标签芯片；**已过期的作业标红**；
- 图片：作业里的插图存在图床里；**图片被清理后，原位显示灰底 + 裂图图标 +「图片已过期」**；
- 右下角编辑按钮：发布作业 / 导出作业（把当前看板导出成 JSON）。

## 三、身份与权限

| 身份 | 看作业 | 用时光机 | 发布作业 | 修改 / 删除作业 |
| --- | --- | --- | --- | --- |
| 游客（未登录） | ✅ | ❌ | ❌ | ❌ |
| 用户 | ✅ | ✅ | ❌ | ❌ |
| 管理员 | ✅ | ✅ | ❌ | ✅ 仅当天 |
| 发布者 | ✅ | ✅ | ✅ | ✅ 仅当天 |

注册后的默认身份是**用户**。要升级某个人：

```sql
update public.profiles set role = 'publisher' where email = 'someone@example.com';
```

（`publisher` = 发布者，`admin` = 管理员，`user` = 用户）

## 四、容量与清理（重要）

用的是 Supabase 免费计划，额度有限，所以**满了会自动删最旧的一整天**：

| 项目 | 上限 | 达到上限时 |
| --- | --- | --- |
| 数据库（作业文字） | **400 MB** | 从最旧一天开始，整天删除记录 |
| 图片桶 | **900 MB** | 从最旧一天开始，整天删除图片 |

清理是**按天整体进行**的：删的是完整的一天（记录和那天的图片一起走），不会只删半天的内容。
被清理后，看板上原本的图片位置会显示「图片已过期」。

另外两件要知道的事：

- **免费项目闲置 1 周会被自动暂停** —— 假期长期没人打开的话，需要去 Supabase 后台手动恢复；
- **免费计划没有自动备份** —— 重要内容建议在桌面端保留导出文件。

## 五、手机端

仓库里的 `mobile/` 是一个 **Android 壳**：把与网页端完全相同的那份页面内置进 App，
所以打开很快，而且**长按图片不会弹出系统菜单**、没有缩放控件、没有滚动边缘光效，看起来更像原生应用。

- 需要自己用 Android Studio 打开 `mobile/` 构建出 APK 安装；
- App 里是**打包那一刻**的页面快照，网页端更新后要重新同步页面并重新出包；
- App 的登录状态和浏览器是**分开**的，需要各自登录一次。

（网页端本身在手机浏览器里也能正常用，界面已经做过手机适配和安全区处理。）

## 安全中心（security.html）

登录后从**个人中心 → 安全中心**进入，可以自助处理账号安全相关的事。

### 更改邮箱：先验证旧邮箱，再验证新邮箱

1. 第 1 步点「发送验证邮件到当前邮箱」→ 去**当前邮箱**点开确认链接（证明这个账号确实属于你）；
2. 回到安全中心后才会出现「新邮箱」输入框 → 填写并提交 → 系统向**新邮箱**再发一封确认邮件；
3. 点开确认后邮箱才真正变更。**在确认完成之前，当前邮箱仍然可用**。

旧邮箱已经登录不上、收不到信？页面里有「**旧邮箱不可用，去申诉**」：弹窗会显示管理员邮箱，
点「打开『电子邮件』」即唤起邮件应用，收件人与主题都已填好，你补上可用的新邮箱即可。

### 更改密码

填写新密码 → 点「发送验证邮件到当前邮箱」→ 点开邮件里的链接后设置新密码。

### 注销账号

1. 点「申请注销，先验证邮箱」→ 系统发送确认邮件；
2. 点开邮件里的按钮回到页面 → **原样输入**这句确认短语（逐字比对，含标点）：

   > 我确认注销账号，并允许服务器将我的账号数据继续存放60天

3. 提交后**立刻从所有设备退出登录**。

之后的时间线：

| 时间 | 发生什么 |
| --- | --- |
| 提交后 | 账号进入注销申请状态，登录入口开始拦截 |
| **3 天内** | **用该账号登录一次 = 自动取消注销**，会提示「已为你取消注销申请，欢迎回来」；邮件里的「取消注销，回到作业」按钮也可以 |
| 满 3 天 | 定时任务把账号标记为**已注销**，此后登录会跳到 `deleted.html` |
| 满 60 天 | 定时任务真正删除账号与数据 |

## 用户管理与封禁

**发布者**在个人中心里有「管理用户」：可以查看全部用户、**设为/移除管理员**、**封禁/解封**。

- 发布者自己那一行不可修改（防呆）；
- **封禁即刻生效**：被封账号的任何页面都会跳到红底的 `ban.html`，且**不能靠退出登录绕过**；
- 服务端同步收紧：`can_edit_now()` 与 `is_publisher()` 都带 `not banned`，被封后发布与修改一律被数据库拒绝；
- **权限实时核对**：客户端每 30 秒、以及每次切回页面、每次操作前都会重新读取角色 —— 撤销管理员后**不需要刷新**就会失去编辑入口。

## 简版与降级链路

老浏览器（例如 iOS 12 的 iPhone 5S）无法解析新版组件库，会**自动降级**：

```
完整版页面
  └─ 检测到浏览器不支持 → unsupport.html?page=<原页面>
        └─ 「去往简版」→ simple/<同名页面>（参数缺失或非法则回主页）

渲染/脚本报错（设备本身支持）→ 只在页面顶部显示红色横幅，不跳转
404 → 纯手写兜底页（返回主页）
ban / deleted → 纯手写页（封禁 / 注销说明 + 联系管理员）
```

简版位于 `simple/`：**一个 `core.js`**（自绘 SVG 图标 + 样式注入 + 全部页面逻辑）+ 每页十几行的外壳，
与完整版**共用同一份登录态**，功能与控件位置对齐，但去掉了动效；
每页顶部常驻红色提示，并提供「重试完整版」。

## 自动维护（数据库定时任务）

| 任务 | 时间 | 作用 |
| --- | --- | --- |
| `purge-unverified-accounts` | 每天 03:00 | 删除**注册满 7 天仍未验证邮箱**的账号 |
| `advance-account-deletions` | 每天 03:15 | 满 3 天的注销申请标记为已注销；满 60 天的真正删除 |

这两个任务也顺带保证了项目**每天都有数据库活动**，免费计划不会因闲置 7 天而被暂停。
